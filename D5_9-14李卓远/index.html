Minecraft 介绍

三个关键词，认识这块方块的世界

01 · 基本信息

什么是 Minecraft？

一款由方块构成的第一人称沙盒游戏。玩家可以在随机生成的世界里采集、建造、合成、冒险，没有固定目标，玩法规则由你定义。

  • 首发年份：2009（公测），2011（正式版 1.0）
  • 核心玩法：生存、创造、极限、多人联机
  • 两大版本：Java 版（PC 生态最丰富）与基岩版（跨平台）
02 · 创始者

Notch 与 Mojang

瑞典程序员 Markus "Notch" Persson 于 2009 年发布了 Minecraft 的第一个公开版本，并随后创立工作室 Mojang（瑞典语"魔法盒"）。

  • 2014 年 Notch 将 Mojang 以约 25 亿美元出售给微软后离场
  • 如今由 Mojang Studios（微软旗下）持续维护更新
03 · 现状

十余年热度不减

Minecraft 是全球销量最高的电子游戏之一，累计销量超过 3 亿份，每月活跃玩家数以千万计。

  • 每年仍有大型版本更新（如"洞穴与高山""幽匿与诡异"）
  • 拥有活跃的模组、材质、地图、服务器创作者生态
  • 衍生作品包括 Minecraft Dungeons、Minecraft Legends 等

Minecraft 下载方式

选一款启动器，把游戏装进电脑

01 · 官方启动器

Minecraft Launcher

由 Mojang / 微软官方提供，支持正版账号登录，可下载 Java 版与基岩版，整合了版本管理、皮肤更换与市场内容。

  • 优点：稳定、正版验证、直接购买/切换版本
  • 适合：已有正版账号、追求原汁原味的玩家
  • 获取：Minecraft 官网 minecraft.net 或微软商店
02 · PCL2

Plain Craft Launcher 2

国内玩家 龙腾猫跃（LTCatt） 开发的开源启动器，界面现代、上手极快，支持版本隔离、模组/整合包一键安装、崩溃自动分析。

  • 仅支持 Windows（依赖 .NET Framework 4.5+）
  • 内置国内加速下载，新手首选
  • 获取：官方爱发电或 GitHub（Meloong-Git/PCL）
03 · HMCL

Hello Minecraft! Launcher

由开发者 黄雨辉 等维护的开源老牌启动器，用 Java 编写，天然跨平台（Windows / macOS / Linux）。

  • 支持的加载器最全：Forge、Fabric、Quilt、NeoForge、OptiFine、LiteLoader
  • 整合包生态最强，可导入 CurseForge / Modrinth / MultiMC
  • 适合：跨平台玩家、整合包与进阶模组玩家

Minecraft 新手教程

第一天该做什么？记住这三步

第一步

撸树 · 合成 · 工具

出生后第一件事：长按左键对准树干采集原木。按 E 打开背包，将原木变成木板，四块木板拼成工作台。

  • 木板 → 木棍 → 木镐 → 石镐
  • 依次升级：木 → 石 → 铁 → 钻石 → 下界合金
  • 前 10 分钟优先做出：镐、斧、剑、火把
第二步

安家 · 火把 · 床

天黑会刷怪。在日落前用泥土/木板围一个小庇护所，插上火把（煤 + 木棍）照明，用三只羊的羊毛 + 三块木板做一张床。

  • 床可以跳过黑夜，并在死亡后作为重生点
  • 门口放一扇门、留一个 1×1 的窗观察怪物
  • 苦力怕爆炸是新手最常见的死因——小心绿色的家伙
第三步

挖矿 · 附魔 · 冒险

往地下挖到 Y=-58 附近找钻石（1.18+ 版本），用铁镐开采。集齐装备后可以下地狱、进入末地挑战末影龙。

  • 附魔台（书 + 钻石×2 + 黑曜石×4）强化装备
  • 铁傀儡 / 村民交易能快速获得资源
  • 进阶：红石自动化、建筑、整合包、服务器
